# WanderLand: AI-Powered Smart Travel Companion

WanderLand is a premium, state-of-the-art Flutter application designed to revolutionize the travel experience. It integrates advanced AI capabilities with social networking and practical travel tools to provide a seamless, safe, and personalized journey for every traveler.

## 🌟 Key Features

### 🤖 Advanced AI Travel Suite
*   **AI Language Survival Kit**: Instantly generates the top 10 most useful local phrases with pronunciation for any destination.
*   **AI Budget Advisor**: Provides personalized, low-cost evening plans based on your remaining daily budget.
*   **Digital Travel Diary**: Summarizes raw trip notes into a beautiful, shareable "Trip Story."
*   **AI Attraction Summarizer**: Quickly provides 3 exciting bullet points about any spot on the map.
*   **Best Time to Visit**: AI-driven insights on the optimal time to visit attractions for the best lighting and fewest crowds.
*   **AI Packing List Generator**: Creates categorized packing lists based on destination, activities, and trip duration.
*   **Predictive Crowd Insights**: Real-time forecasting of crowd levels at popular locations.

### 📍 Smart Social Navigation
*   **Interactive Discovery Map**: Real-time place discovery with live community updates.
*   **Community Updates**: Share tips, warnings, and live photos of locations with the travel community.
*   **Group Chat & Coordination**: Real-time messaging with integrated travel tools and group polls.
*   **Trip Posting**: Create and join trips to find the perfect travel companions.

### 💰 Expense & Budget Management
*   **Smart Expense Tracker**: Log expenses by category with multi-user support.
*   **Dynamic Bill Splitting**: Select exactly who is involved in an expense and settle up with ease.
*   **Notifications**: Automated alerts for group expenses and budget updates.

### 🛡️ Safety & Reliability
*   **Smart SOS Widget**: Global floating button for instant access to local emergency services and personal contacts.
*   **Offline Support**: Local SQLite database ensuring your data is always accessible.

## 🚀 Technology Stack
*   **Framework**: Flutter (Dart)
*   **AI Provider**: Groq Cloud (Llama 3.3 70B)
*   **Data Sources**: OpenTripMap API, OpenWeatherMap API
*   **Local Backend**: SQLite for robust offline-first performance
*   **State Management**: Modern, reactive UI patterns

## 🛠️ Getting Started

### Prerequisites
*   Flutter SDK (Latest stable version)
*   Groq API Key
*   OpenTripMap API Key

### Configuration
1. Clone the repository:
   ```bash
   git clone https://github.com/hamdan-ishfaq/MAD_PROJECT.git
   ```
2. Create a `.env` file in the root directory and add your API keys:
   ```env
   GROQ_API_KEY=your_groq_key
   OPENTRIPMAP_KEY=your_otm_key
   WEATHER_API_KEY=your_weather_key
   GROQ_MODEL=llama-3.3-70b-versatile
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```
